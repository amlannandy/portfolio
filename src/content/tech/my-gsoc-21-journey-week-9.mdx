The goal here was to ensure better interaction and collaboration inside every project. One of the ways to do that was to provide chat functionality in every team so that members can better discuss progress on the project and divide tasks among themselves.

## Implementation

The backend implementation of the chat functionality was already done in Week 4 (You can read about it [here](/blogs/tech/my-gsoc-21-journey-week-4)). For maintaining a live feed of messages, I used web sockets, more specifically socket.io to achieve it. Flask provides a great package [Flask-SocketIO](https://flask-socketio.readthedocs.io/en/latest/) to implement in the backend.

Moving on to the frontend, I used [socket.io-client](https://www.npmjs.com/package/socket.io-client) which is the JavaScript client for socket.io in order to connect to the backend. Here, I basically had to handle 2 events -

1. **_send_message_** - Used to send messages.
2. **_receive_message_** - Used to detect when some other user has sent a message. It is automatically triggered when any user sends a message.

These 2 events working in tandem help in ensuring that the user always views a live feed of messages in the web application.
